PACKAGE RECORD

data.table

Extension of `data.frame`

VERSION 1.18.6.1LICENSE MPL-2.0 | file LICENSE
01 / FROM THE OFFICIAL PACKAGE INDEX

Description

Fast aggregation of large data (e.g. 100GB in RAM), fast
ordered joins, fast add/modify/delete of columns by group using
no copies at all, list columns, friendly and fast
character-separated-value read/write. Offers a natural and
flexible syntax, for faster development.
